BROWSER-AUTOMATION NOTE
The Chromium binary in this execution environment hangs even on a minimal data: page,
so a genuine WebKit/iOS or Chromium graphical automation run could not be completed here.
The build was instead validated with:
- the exact game JavaScript in a simulated DOM harness,
- an IndexedDB/Service Worker API harness,
- static 390px mobile rendering,
- source/manifest/service-worker validation.
A real iPhone smoke test after publishing to GitHub Pages is still recommended because
only iOS Safari/WebKit can fully validate Home Screen installation and safe-area behavior.
